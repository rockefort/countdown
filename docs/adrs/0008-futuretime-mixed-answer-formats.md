# ADR-0008: Hva er klokken om — Mixed Answer Formats

## Status

Accepted

## Context

"Hva er klokken om...?" shows a fixed start time and asks "Hva er klokken om X?" (e.g. "Hva er klokken om en halvtime?"). The learner picks from 4 multiple-choice answers. The key design question is how answer options are represented — as digital times (`HH:MM`) or Norwegian text.

## Decision

**Mix answer formats randomly per question.** For each question, ~50% of the time answers are digital times, ~50% Norwegian text. The correct answer's format is also chosen randomly by the same coin-flip, so the learner can't predict the format.

### Offset descriptors

The question's offset text ("om X") is generated by level:

- **Levels 1-4** use exact descriptors via `offsetText(min)` (e.g. "en time", "en halvtime", "et kvarter", "fem minutter").
- **Level 5** uses approximate language via `approximateOffsetText(min)` (e.g. "om omtrent en halvtime", "om litt mer enn en halvtime") — consistent with the approximate-language theme of level 5.

### Distractor generation

Three distractors are generated as nearby valid times for the level:
- Try other offsets from the level's allowed set, same format as the correct answer.
- Fall back to random valid times if not enough unique distractors.
- No duplicate options (dedup via a seen-set).

### Target calculation

`targetTime = (startMinutes + offset) % 1440`, so offsets can wrap across midnight naturally.

## Consequences

- Learners practice both reading a clock face **and** converting an offset in both digital and spoken Norwegian.
- ~50/50 split means mixed practice rather than predictable format.
- Dedup ensures all 4 options are always distinct.
- Level 5's approximate language aligns with the "omtrentlig" reading skill.
